# Year-Project
Drone-based 3D Mapping and Modelling that captures car 
accidents scenes and generates the images in a form of a pdf 
report and to be displayed on a user’s portal. Front-end: HTML, 
CSS and JavaScript for the user’s portal to view accident scenes 
details and login. MySQL that stores vehicle and accident data 
along with the user’s data. Backend: Express.JS and node.js for 
static files, Flask for API routing and orchestration. Python for 
function the DJI Trello drone from its code and generating pdf 
reports of the accident scenes.
